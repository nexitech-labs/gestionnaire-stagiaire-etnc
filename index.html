    Accès au dossier du projet

    L'application enregistre ses données dans db/ccpg.db. Sélectionnez le dossier racine du projet (celui qui contient index.html).

    Chemin du dossier

    Le chemin est copié automatiquement : dans la fenêtre Windows, collez-le (Ctrl+V) dans le champ « Dossier », puis validez.
